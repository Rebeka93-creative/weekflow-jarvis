# Changelog

All notable changes to WeekFlow are documented here.

## [1.0.0] — 2026

### Added
- Initial release
- Week view with 7-column grid, real date navigation, drag-and-drop
- Project view with per-project progress tracking
- Alerts centre — overdue, deadlines, high priority, due in 3 days
- User panel — profile, productivity stats (streaks, bar chart), Pomodoro timer, agenda, scratch pad
- J.A.R.V.I.S voice system (Web Speech API) with smart queuing and deduplication
- 7-layer procedural ambient music synthesizer (Web Audio API)
- Item fields: type, date range, time, duration, priority, daily reminder, prep notes, notes
- Right-click context menu (edit, mark done, duplicate, delete)
- Live search with match highlighting
- Real-time clock in header
- Energy core ring driven by week completion percentage
- Persistent localStorage with migration from previous versions
- Digital rain background, glassmorphism cards, HUD corner brackets
- Stitch design system tokens (S.Y.S.T.E.M. CORE aesthetic)
- Bottom navigation bar with Material Symbols icons
- Mobile responsive layout
